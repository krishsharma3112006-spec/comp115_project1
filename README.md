# A Peaceful Landscape with Python Turtle

## Description

This project creates a simple and colourful Python program that draws a peaceful outdoor landscape using the `turtle` graphics library. The drawing includes a bright sun, mountains, green grass, a blue river, trees, and small flowers.

The program demonstrates basic concepts in Python graphics, including:

* Drawing shapes (circles, rectangles, and triangles)
* Using functions to organize and reuse code
* Using loops to draw repeated objects
* Changing colours and positions to create a landscape

## Code Overview

The project is structured around reusable functions:

* `rectangle(x, y, width, height, colour)` – Draws a coloured rectangle.
* `circle(x, y, size, colour)` – Draws a filled circle.
* `triangle(x1, y1, x2, y2, x3, y3, colour)` – Draws a filled triangle.
* `tree(x, y)` – Draws a tree using simple shapes.

The functions are used to create different parts of the landscape. A loop is also used to draw multiple flowers, making the drawing easier to create and organize. The screenshot of the drawing is as below:

## How to Run

1. Clone or download this repository.
2. Open the project file `peaceful_landscape.py` in your Python IDE or text editor.
3. Run the program:

```bash
python peaceful_landscape.py
```
